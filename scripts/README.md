# scripts/

Every analysis, figure, and table in the paper is regenerated by a
script in this directory.  Naming conventions:

| Prefix              | Purpose                                           |
| ------------------- | ------------------------------------------------- |
| `_*.py`             | private / shared infrastructure (not stand-alone) |
| `cross_sample_*.py` | training drivers (writes NPZ + manifest sidecar)  |
| `analyze_*.py`      | per-experiment analyses (often emit CSV + table)  |
| `make_*.py`         | paper-figure or paper-table generators            |
| `*.sh`              | shell launchers / parallel dispatchers            |

## Source-of-truth chain

```
NPZ (cross_sample_train.py)
  → CSV (analyze_*.py / make_*_table.py)
    → paper/sections/tables/*.tex                  (table fragments)
    → paper/sections/macros.tex (make_paper_macros.py)
                                                   (every quoted number)
```

Every prose number in `paper/sections/*.tex` references a `\newcommand`
defined in `macros.tex` — no literal numbers.  After any retraining,
`make tables` regenerates the entire chain.

## Private (shared) modules

| Module                | Provides                                                                     |
| --------------------- | ---------------------------------------------------------------------------- |
| `_analysis_lib.py`    | `load_runs`, `pairwise_metrics`, `bootstrap_ci`, `bootstrap_paired`, `GLOBS` |
| `_provenance.py`      | `make_context` for writing manifest JSON sidecars                            |
| `paper_constants.py`  | dataset partitioning (headline / borderline / excluded), method ordering, λ values, display names |

## After retraining

```bash
make analysis    # CSVs from NPZs
make tables      # .tex fragments from CSVs (also runs `make macros`)
make figures     # PDFs from NPZs
```

Then `cd paper && latexmk -pdf main.tex`.
