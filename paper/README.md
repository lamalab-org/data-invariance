# Paper directory — NeurIPS 2026 submission

## Contribution type

**Use-Inspired** (NeurIPS 2026 reviewer guidelines).

The work frames methods around the deployment realities of small-N
from-scratch scientific ML (drug discovery, materials), and provides
empirical evidence on standard chemistry benchmarks (MoleculeNet, TDC
ADME/Tox). Reviewers should evaluate whether:

- the use case is genuine (Section 1),
- the methods align with domain needs (Sections 5–6),
- the work yields insight beyond the application (Sections 3, 7).

## Build

```
cd paper/
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

## Tables and figures

Every paper table is regenerated from saved NPZ predictions with one
command:

```
make -f Makefile.paper tables
```

This populates `paper/sections/tables/*.tex` and writes companion CSVs
to `outputs/`. Re-running tables does not require any model retraining.
